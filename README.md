# 호이안 · 다낭 일정표 PWA 배포 패키지

## 구성
- `index.html`: 일정표 + 실제 지출 계산기
- `manifest.webmanifest`: 아이폰 홈 화면 앱 이름/아이콘 정보
- `sw.js`: 오프라인 캐시용 서비스 워커
- `icons/`: 홈 화면 아이콘

## 가장 쉬운 배포
1. GitHub에서 새 repository 생성
2. 이 폴더 안의 파일 전체 업로드
3. Settings → Pages → Deploy from a branch → `main` / root 선택
4. 생성된 `https://...github.io/.../` 주소를 iPhone Safari에서 열기
5. 공유 버튼 → 홈 화면에 추가

## 주의
- 지출 입력값은 브라우저 localStorage에 저장됩니다.
- 같은 아이폰, 같은 배포 주소에서 열어야 입력값이 유지됩니다.
- 주소가 바뀌면 저장소가 달라져 기존 입력값이 안 보일 수 있습니다.
